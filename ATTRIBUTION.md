# Attribution and scope

This is a collection of personal application, integration, and prototype work. It is not a claim of authorship of dependencies, downloaded assets, models, datasets, or upstream projects.

- Crispy GB and mGBA Studio integrate the mGBA emulator core. The upstream core is excluded here. A runnable distribution must satisfy the applicable upstream license and source obligations.
- Crispy Core is a separate experimental implementation. External test suites are not included as original work.
- GBA Studio and the REA launcher use existing tooling and source projects. REA, OpenCode, Ollama, binutils, and upstream game source are external contributions; recovered drafts do not establish equivalent native games.
- Monster Forge uses an external monster reference dataset; the dataset is not bundled here.
- ComfyUI, Ollama, Phaser, Electron, Express, React, Vinext, and other dependencies retain their own authorship and licensing.
- Existing Webador site exports, generated design handoffs, external art, and downloaded asset libraries are excluded from the source catalogue where provenance or redistribution needs further review.

Existing license/copyright notices in included source are retained. No new blanket license has been applied. Check individual ownership and dependency obligations before redistributing a runnable release or making this repository public.
