# Personal Projects

A portfolio of independent development projects spanning IT workflows, networking, local AI, desktop applications, and creative tools.

## Selected practical projects

- [Toner request systems](projects/toner-systems/README.md): web forms, administration, SQL, and notifications.
- [Networking tools](projects/networking-tools/README.md): Python IPv4 calculations and VLSM planning.
- [Business forms](projects/business-forms/README.md): browser-based document previews and exports.
- [Mac Ledger](projects/mac-ledger/README.md): filesystem metadata inventory and comparisons.
- [Monster Forge](projects/monster-forge/README.md): local model integration, validation, and persistence.

## Reading this portfolio

Project summaries describe functionality visible in local source and documentation. Applications and tests were not freshly executed for this publishing review. Prototype status and upstream contributions are identified in each project.

Source folders contain selected, privacy-filtered text snapshots. They deliberately omit data, assets, credentials, local paths, and personal working notes. They may not run without omitted resources and configuration; no production deployment or adoption metrics are claimed.
