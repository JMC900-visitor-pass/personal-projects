# Privacy and publishing

This repository starts with a new Git history. It contains a curated project catalogue and selected source snapshots.

Excluded material includes personal notes and interview preparation, CV drafts, credentials and environment files, private databases, save files, model weights, ROMs, generated stories/world notes, binaries, and downloaded assets. Contact email addresses and local home paths are replaced in source copies.

The local publishing tool only stages an explicit file list. It scans text and paths, requires an exact approved snapshot, and checks committed history before pushing. Unapproved changes and unexpected files block publishing. Scanner findings contain file locations and categories, never secret values.

Pattern scanning cannot prove that arbitrary text contains no private information. Human review remains necessary before approving changed source. New or changed source snapshots do not automatically acquire approval. No background job reads the original projects or expands the source list.

The source projects remain untouched. Publishing tools, local audit records, approvals, and connection settings live outside this repository.
