# Spark Battle Design and Card Tools

Develop a tabletop card-game ruleset and supporting design utilities.

## Implemented work

Documented classes, keywords, resources, and combat rules; structured prompt libraries; browser card editing/export; an Ollama-connected card-generation interface.

## Status and limitations

Game-design and tooling project. A complete released game or commercially validated balance is not established.

## Source snapshot

2 selected text source files are included. These are portfolio snapshots, not a guaranteed complete runnable distribution. Personal notes, original documentation, local databases, saves, credentials, generated content, binaries, and artwork are excluded. Local user paths and non-example email addresses are replaced in the copies. Runtime defaults may therefore need configuration.

External libraries, models, datasets, and upstream projects remain credited to their authors. No blanket license or claim of sole authorship is made for this collection.

## Architecture and design decisions

A shared rules reference supports consistent card definitions. Editable card text is separated from artwork. The full rulebook and generated content are excluded from this source snapshot.
