# Shrimp Brain Simulation and Combat Lab

Explore explicit rules and data through interactive simulations.

## Implemented work

CSV-informed, seeded behavioural trials; a Tkinter aquarium with persisted state and lifecycle rules; synthetic JSON/CSV exports. Combat Lab provides configurable opposed dice rolls, a probability grid, health tracking, and optional rule variants.

## Status and limitations

Separate simulation prototypes grouped here by theme. Shrimp Brain explicitly describes its trajectories as synthetic and its model as scientifically unvalidated. Combat Lab explores working rules rather than proving a balanced game.

## Source snapshot

11 selected text source files are included. These are portfolio snapshots, not a guaranteed complete runnable distribution. Personal notes, original documentation, local databases, saves, credentials, generated content, binaries, and artwork are excluded. Local user paths and non-example email addresses are replaced in the copies. Runtime defaults may therefore need configuration.

External libraries, models, datasets, and upstream projects remain credited to their authors. No blanket license or claim of sole authorship is made for this collection.

## Architecture and design decisions

Seeds support repeatable synthetic behaviour. Persisted state supports continuation. Simulated outputs are distinct from observations; enumerated dice pairs give probabilities under explicitly selected rules.
