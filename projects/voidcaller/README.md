# Voidcaller RPG and Content Forge

Create a configurable creature RPG with a companion content-authoring tool.

## Implemented work

Creature and move models; turn-based combat; progression and skill trees; party/equipment management; content validation; save migration; a shared character-grid interface with ANSI and Pygame rendering; content-authoring workflows.

## Status and limitations

Substantial personal game prototype with documented incomplete systems. Browser gameplay is partial, and several advanced progression/content features are deferred. Count related folders as one project family.

## Source snapshot

57 selected text source files are included. These are portfolio snapshots, not a guaranteed complete runnable distribution. Personal notes, original documentation, local databases, saves, credentials, generated content, binaries, and artwork are excluded. Local user paths and non-example email addresses are replaced in the copies. Runtime defaults may therefore need configuration.

External libraries, models, datasets, and upstream projects remain credited to their authors. No blanket license or claim of sole authorship is made for this collection.

## Architecture and design decisions

Structured content and a modular engine separate rules from authored records. A shared character grid supports ANSI and Pygame rendering; save migration supports evolving data formats.
