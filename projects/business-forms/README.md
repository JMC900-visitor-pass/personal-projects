# Business Forms Application

Produce common business paperwork through one browser interface.

## Implemented work

Receipt, quotation, pre-quotation, invoice, and payment-plan forms; live document previews; totals, tax, and balance calculations; PDF, Word-compatible, and Excel exports; file naming and browser folder-saving options.

## Status and limitations

Browser application implementation with usage instructions. This snapshot uses a placeholder business identity and excludes the original embedded logo. Browser support and export fidelity need checking in the intended environment; some libraries require an initial internet connection.

## Architecture and design decisions

A browser interface combines data entry and live preview. Document exports reuse entered data. Embedded business contact defaults are replaced and the logo is removed in this portfolio copy.
