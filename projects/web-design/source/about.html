Page 2 · How the pieces fit

What am I looking at?

  1. HTML describes the page: headings, paragraphs, links, buttons and forms. Every page here is its own .html file.
  2. CSS styles those elements. All three pages link to styles.css, so one change there can affect every page.
  3. JavaScript responds to events. All three pages load script.js. It checks whether a particular button or form exists before using it.

Follow one change

On Home, find id="count-button". In script.js, find getElementById('count-button'). That is how the script finds that exact HTML element. Click the button to see the result.

Try another change

In styles.css, change --accent near the top. Reload this page and the others to see which elements use that colour.

Tip: right-click a page in your browser and choose Inspect to connect visible elements to their HTML and CSS.
