# Website Review and Educational Web Starter

Improve website structure and provide a small example for learning web fundamentals.

## Implemented work

Local website-content inventory and improvement proposal; six-screen design export; three-page educational website with shared styling, a counter, a demo form, and guided exercises.

## Status and limitations

Review/design and educational work. The original CME site is a Webador export, and the redesigned screens are a generated design handoff; neither establishes original authorship of the existing live site or a deployed redesign. The starter contact form does not send messages. Business/site identity and ownership review is still needed before including those source files.

## Source snapshot

5 selected text source files are included. These are portfolio snapshots, not a guaranteed complete runnable distribution. Personal notes, original documentation, local databases, saves, credentials, generated content, binaries, and artwork are excluded. Local user paths and non-example email addresses are replaced in the copies. Runtime defaults may therefore need configuration.

External libraries, models, datasets, and upstream projects remain credited to their authors. No blanket license or claim of sole authorship is made for this collection.

## Architecture and design decisions

The educational example uses plain HTML, CSS, and JavaScript to make structure, styling, and events visible. Existing business website exports and design handoff assets are withheld pending ownership and identity review.
