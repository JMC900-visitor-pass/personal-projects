# Realm Chips and Browser RPG Experiments

Explore reusable RPG systems and browser/desktop game delivery.

## Implemented work

Phaser/TypeScript scenes, state, map-loading, and combat modules in the RPG projects; Electron packaging configuration in Realm Chips; rendering, input, enemy behaviour, and item-system experiments in the JavaScript hack-and-slash project.

## Status and limitations

Related prototypes at different stages. Configured Windows/Linux build targets do not establish that packages were built and tested on those systems.

## Source snapshot

18 selected text source files are included. These are portfolio snapshots, not a guaranteed complete runnable distribution. Personal notes, original documentation, local databases, saves, credentials, generated content, binaries, and artwork are excluded. Local user paths and non-example email addresses are replaced in the copies. Runtime defaults may therefore need configuration.

External libraries, models, datasets, and upstream projects remain credited to their authors. No blanket license or claim of sole authorship is made for this collection.

## Architecture and design decisions

Phaser supplies scene and rendering infrastructure, while TypeScript clarifies interfaces and structured data. Packaging configuration alone does not establish tested cross-platform releases.
